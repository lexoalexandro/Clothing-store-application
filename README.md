# Store app (მთავარი / საწყობი) - desktop version

Folder layout:
```
store-app/
  app.py
  build_windows.bat
  run_test_windows.bat
  static/index.html
```

Test without building: double-click `run_test_windows.bat`
Build the .exe:        double-click `build_windows.bat`  -> result in `dist\Magazia_v1.8.exe`

Data (products, stock, sales) is stored in `C:\Users\<your name>\StoreApp\store.db`.
Back it up by copying that one file.
